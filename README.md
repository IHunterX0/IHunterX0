# 1001 Çalışma Kitapları + C.A.R.V.I.S.

Paket: `com.dogac.bin1`. Bu repo, tabletteki APK'dan kurtarılan **web arayüzü kodunu** (`www/`) içerir.

- `www/` → APK içindeki `assets/www` (HTML/JS). Kitap içerikleri (`kitaplar/`), 3B/molekül verileri (`lab/`)
  ve Vosk Türkçe ses modeli (`assets/vosk-tr`) boyut ve telif nedeniyle repoda yok; APK'nın içinde duruyorlar.
- Android (Kotlin) tarafı (`MainActivity`, `CarvisServis`, `CarvisErisim`, `CarvisBildirim`, `AcilisAlici`, `Cihaz`)
  henüz kaynak koda çevrilmedi.
